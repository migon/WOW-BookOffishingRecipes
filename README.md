# ?? Book of Fishing Recipes

A comprehensive World of Warcraft addon designed for dedicated fishermen and cooks. Never wonder where to find a recipe or whether you have the skill to catch a specific fish again!

*Note: Optimized for the modern WoW API (Dragonflight client) while containing Classic era data (e.g., WoW Forever server).*

## ? Features

- **?? The Ultimate Fish Database**: Browse a complete list of cookable, consumable, and crafting-related fish.
- **?? Live Skill Tracking**: The addon monitors your current Fishing and Cooking levels in real-time.
- **?? Smart UI Indicators**: 
  - ?? Backpack icon if the fish is currently in your bags.
  - ?? Fishing Pole icon if you have the required skill to catch it.
  - ?? Food icon if you have the required cooking skill for its recipe.
- **?? Map & Targeting Integration**:
  - **Left-Click** on a vendor's name to instantly place a Map Marker (or TomTom waypoint) directly to their location.
  - **Shift-Click** on a vendor to insert a ready-to-use `/tar VendorName` macro into your chat edit box for easy targeting.
- **?? Enhanced Tooltips**: Instantly see required fishing levels, recipe sources, and cooking requirements just by hovering over a fish in your inventory.

## ?? Installation

1. Download the latest version from this repository (Code -> Download ZIP).
2. Extract the ZIP file.
3. Copy the **inner** `BookOfFishingRecipes` folder.
4. Paste it into your WoW Addons directory (e.g., `World of Warcraft\_classic_era_\Interface\AddOns\`).
5. Start the game and make sure "Load out of date AddOns" is checked.

## ?? Usage

- Type `/bfr` in the game chat to open the Book of Fishing Recipes.
- Use the collapsible categories on the left to browse fish.
- Check the detail panel on the right for vendor locations, minimum levels, and recipe costs.
